# Irina Bogovich Slideshow

Лёгкое fullscreen slideshow на чистом HTML/CSS/JS для публикации через GitHub Pages.

## Что уже сделано

- `index.html` содержит один экран с большим изображением, текстом, навигацией и кнопкой музыки.
- `style.css` оформляет mobile-first версию с акцентом на iPhone и GitHub Pages.
- `script.js` содержит массив `slides`, автосмену, паузу, навигацию, счётчик и ручной запуск музыки.

## Куда вставлять фото

1. Поместите изображения в `assets/images/`.
2. В начале `script.js` замените значения `image` в массиве `slides` на пути вида:

```js
image: "assets/images/your-photo.jpg"
```

Сейчас slideshow использует уже существующие изображения из `assets/labels/web/`, чтобы страница сразу открывалась без пустых экранов.

## Куда вставлять музыку

1. Поместите аудиофайл в `assets/audio/`.
2. В `script.js` укажите путь в переменной `audioTrack`, например:

```js
const audioTrack = "assets/audio/your-track.mp3";
```

На iPhone музыка запускается только вручную через кнопку.

## Где менять тексты

Все тексты слайдов лежат в начале `script.js` в массиве `slides`:

- `wine` отвечает за малый заголовок
- `title` отвечает за крупный заголовок
- `text` отвечает за основной текст

## Как открыть локально

- Самый простой вариант: открыть `index.html` в браузере.
- Если нужен локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Что загрузить в GitHub

Загрузите в репозиторий весь проект целиком:

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- папку `assets/`

После загрузки включите GitHub Pages для ветки и корня репозитория.

Если `assets/images/` и `assets/audio/` останутся пустыми, GitHub их не покажет. Добавьте туда хотя бы реальные файлы перед публикацией.
